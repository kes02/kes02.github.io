### 문제
https://www.acmicpc.net/problem/2468

### 해답
```java
import java.util.Scanner;

public class Main {
    static int size;
    static int[][] heights; // 각 지역의 높이
    static boolean[][] visited;

    static int[] moveX = {-1, 1, 0, 0}; // 위, 아래
    static int[] moveY = {0, 0, -1, 1}; // 왼쪽, 오른쪽

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        size = sc.nextInt();
        heights = new int[size][size];
        int maxHeight = 0;

        for (int i = 0; i < size; i++) {
            for (int j = 0; j < size; j++) {
                heights[i][j] = sc.nextInt();
                maxHeight = Math.max(maxHeight, heights[i][j]);
            }
        }

        int maxSafeAreas = 0;

        // 비가 최대 높이까지 옴
        for (int rainLevel = 0; rainLevel <= maxHeight; rainLevel++) {
            visited = new boolean[size][size];
            int safeAreaCount = 0;

            // 모든 지점을 확인
            for (int i = 0; i < size; i++) {
                for (int j = 0; j < size; j++) {
                    // 아직 방문하지 않았고, 비에 잠기지 않는 지역이면
                    if (!visited[i][j] && heights[i][j] > rainLevel) {
                        dfs(i, j, rainLevel); // 연결된 안전영역 탐색
                        safeAreaCount++; // 안전영역 개수 증가
                    }
                }
            }

            maxSafeAreas = Math.max(maxSafeAreas, safeAreaCount);
        }

        System.out.println(maxSafeAreas);
        sc.close(); // Scanner 리소스 해제
    }

    static void dfs(int x, int y, int rainLevel) {
        visited[x][y] = true; // 현재 위치 방문 표시

        // 상하좌우 탐색
        for (int i = 0; i < 4; i++) {
            int nextX = x + moveX[i];
            int nextY = y + moveY[i];

            if (nextX < 0 || nextY < 0 || nextX >= size || nextY >= size) {
                continue;
            }

            if (visited[nextX][nextY]) {
                continue;
            }

            // 비에 잠기지 않는 지역이면 계속 탐색
            if (heights[nextX][nextY] > rainLevel) {
                dfs(nextX, nextY, rainLevel);
            }
        }
    }
}
```

### 배운점
DFS의 정석 같은 문제
최대 O(n*n)의 시간복잡도였고, maxHeight로 입력된 map의 최대 높이를 구하였고, 이중 for문으로 모든 지점을 탐색하도록 하였음. 이때 dfs를 통해 safe area를 찾도록 하는 문제였음.

dfs 사용시에 경계 부분에 대한 조건문은 꼭 작성해야 한다고 생각함.
