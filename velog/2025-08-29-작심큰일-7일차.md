### 문제
https://www.acmicpc.net/problem/4963

### 해답
```java
import java.util.*;

public class Solution {
    static int w, h;
    static int[][] map;
    static boolean[][] visited;
    static int[] dx = {-1, -1, -1, 0, 0, 1, 1, 1};
    static int[] dy = {-1, 0, 1, -1, 1, -1, 0, 1};

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        while (true) {
            w = sc.nextInt();
            h = sc.nextInt();
            if (w == 0 && h == 0) break;

            map = new int[h][w];
            visited = new boolean[h][w];

            for (int i = 0; i < h; i++) {
                for (int j = 0; j < w; j++) {
                    map[i][j] = sc.nextInt();
                }
            }

            int count = 0;
            for (int i = 0; i < h; i++) {
                for (int j = 0; j < w; j++) {
                    if (map[i][j] == 1 && !visited[i][j]) {
                        bfs(i, j);
                        count++;
                    }
                }
            }

            System.out.println(count);
        }
    }

    static void bfs(int y, int x) {
        Queue<int[]> q = new LinkedList<>();
        q.add(new int[]{y, x});
        visited[y][x] = true;

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int cy = cur[0];
            int cx = cur[1];

            for (int dir = 0; dir < 8; dir++) {
                int ny = cy + dy[dir];
                int nx = cx + dx[dir];

                if (ny >= 0 && ny < h && nx >= 0 && nx < w) {
                    if (map[ny][nx] == 1 && !visited[ny][nx]) {
                        visited[ny][nx] = true;
                        q.add(new int[]{ny, nx});
                    }
                }
            }
        }
    }
}
```

### 배운점
cur 위치를 기준으로 상하좌우대각선 을 탐색하기 때문에 dir를 static으로 정의하고 사용하도록 하였다. 
탐색하는 문제를 풀 때 이런 상하좌우대각선 문제가 자주 나오는데 이것 또한 외워두면 좋을 것 같다.
그리고 Queue 자료형에 배열을 입력해두고 큐에서 꺼내 탐색하는 방식으로 작성하였다. 
그러나 모범답안에서는 큐를 활용하지 않고 재귀함수 방식으로 작성하였는데 이 부분으로 작성하는게 좀 더 코드가 덜 복잡하고 효율적이라는 생각이 들었다.
