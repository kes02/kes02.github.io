아래 3가지를 주요 기능으로 제공하고 있습니다.
1. 수도권/대전/대구/부산 지하철 랜덤 뽑기 기능
2. 지하철역 랜덤 뽑기 기능
3. 할일 랜덤 뽑기 기능

### 만들게 된 계기
데이트 또는 놀러다닐 때 어디를 갈지 선택하기 어렵거나 이걸 하나의 컨텐츠로 소비하게 되는 것을 보게 되었습니다.
물론 아날로그식으로 종이에 작성하고 뽑는 것도 좋지만, 저는 그냥 이미 만들어진 웹 또는 앱에서 룰렛을 돌리고 싶었던 것 같습니다.
그래서 lovable + gemini를 사용하여 만들게 되었습니다.

### 왜 저 기능을 제공하는가?
Q1. 왜 지하철 뽑기, 역 뽑기, 할일 뽑기 기능만이 있나요?
A1. 릴스 같은 것을 보신 분들은 아시겠지만 '랜덤 데이트'라는 것을 들어보셨을 수도 있습니다.
보통 사람들이 어떤 지하철을 탈지 -> 그럼 그 지하철에서 어느 역을 갈지 -> 뭘할지
이런 로직으로 선택하는 것을 바탕으로 3가지 기능에 한해 개발했습니다.

Q2. 그냥 카카오에서 제공하는 사다리타기나 룰렛돌리기 하면 안 되나요?
A2. 사용해보니까 작성하는 것도 번거롭고 결과값을 친구들과 공유하기 위해 캡쳐해서 보내는게 피로했습니다.

Q3. 서울, 수도권은 왜 나누셨나요?
A3. 지하철이 인천, 경기도권까지 이어져있어서 여기까지 랜덤으로 결과가 나오면 가기 어려울 것 같단 생각도 들더라고요. 그래서 사용자에게 서울권에 있는 지하철 역만 랜덤으로 돌릴지 아니면 인천, 경기도 상관없이 랜덤으로 돌릴지 이런 선택권을 주고 싶었습니다.

Q4. 뽑기 결과나 작성한 카테고리가 어디 저장되는건 아니죠?
A4. 어디에도 저장하지 않는 웹 사이트 입니다.

Q5. 사이트 이름이 '랜덤 데이트'라고 하는데 데이트 할 때만 사용해야 하나요?
A5. 아닙니다. 그냥 평소에 오늘 밥 뭐 먹지? 이런식으로 생각하고 사용하셔도 됩니다. 

Q6. 왜 접히는 방식인가요? 
A6. 모바일에서 사이트를 열었을 때를 생각해보니, 스크롤을 하는게 불편하겠다 또는 복잡하다 라는 생각이 들 것 같아서 필요한 부분만 열었다 폈다하면서 쓸 수 있게 했습니다.

### 어떻게 개발했는가?
[lovable](https://lovable.dev/)이라고 기획한 것을 프롬프트에 작성하면 프론트/백을 개발해주는 사이트가 있습니다. 특히, 배포까지 된다는게 장점인데.... 문제는 크레딧 제도라 free에서는 달에 30크레딧, 하루에 최대 5크레딧 사용이 가능해서 제가 이걸 다 써버렸습니다.
또한 단점으로는 free에서는 직접 코드 수정이 불가능합니다.
그래서 깃헙에 업로드된 이 코드를 base로 제가 수정하여 개발하였습니다.

### 개발 후기
평소 놀러다니다보면 한 번쯤 컨텐츠로 랜덤으로 놀러갈 곳 정하기 라는걸 해보고 싶었습니다.
그래서 룰렛도 돌려보고 사다리타기도 해보니까 생각보다 번거로워서 집가서 이걸 만들어보자! 라는 생각으로 바로 만들게 되었습니다.
AI가 작성해준 코드를 컴퓨터에서 실행했을 때는 정상동작 되었지만 모바일에서 버그가 발견되어 아쉽다는 생각을 많이 했습니다.

그래도 이렇게 아이디어를 기획하고 AI에게 개발해달라고 해서 MVP를 만들고, 초기 사용자 검증에는 아주 유용할 것 같습니다.
