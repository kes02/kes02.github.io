### 문제
https://www.acmicpc.net/problem/2437

### 해답
``` java
import java.util.Arrays;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        int n = sc.nextInt();
        int[] weights = new int[n];
        
        for (int i = 0; i < n; i++) {
            weights[i] = sc.nextInt();
        }
        
        Arrays.sort(weights);
        
        int maxMeasurable = 0;
        
        for (int i = 0; i < n; i++) {
            // maxMeasurable + 1은 측정할 수 없는 무게가 됨
            if (weights[i] > maxMeasurable + 1) {
                break;
            }
            
            maxMeasurable += weights[i];
        }
        
        System.out.println(maxMeasurable + 1);
    }
}
```

정렬을 하게 되면 1, 1, 2, 3, 6, 7, 30으로 정렬이 된다. 
i=0일 때 1은 max=0인 상태에서 +1을 하면 1, 1>1로 1은 max에 더해지고 max=1이 된다.
i=1일 때 1은 max=1인 상태에서 +1을 하면 2, 1>2로 1은 max에 더해지고 max=2가 된다.
i=2일 때 2는 max=2인 상태에서 +1을 하면 3, 2>3로 2는 max에 더해지고 max=4가 된다.
i=3일 때 3은 max=4인 상태에서 +1을 하면 5, 3>5로 3은 max에 더해지고 max=7이 된다.
i=4일 때 6은 max=7인 상태에서 +1을 하면 8, 6>8로 6은 max에 더해지고 max=13이 된다.
i=5일 때 7은 max=13인 상태에서 +1을 하면 14, 7>14로 7은 max에 더해지고 max=20이 된다.
i=6일 때 13은 max=20인 상태에서 +1을 하면 21, 30>21로 break된다.
이때 max=20이고 무게는 21부터 측정할 수 없다.

### 배운점
그리디로 풀기 위해 입력 받은 무게를 오름차순으로 정렬한 후 O(n)의 반복문을 통해 구하도록 하였다.
+1을 하는 이유는 저울추가 N는 1이상인 양의 정수이고, 올려진 저울추와 작거나 같을 경우는 측정할 수 있으나 초과한 경우에는 측정할 수 없기 때문이다.
