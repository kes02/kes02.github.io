# 구글 시트의 장점
1. 시트 기반 가시화된 DB로 사용할 수 있다.
2. Appscript는 다음과 같이 기능별로 파일을 나눌 수 있다.![](https://velog.velcdn.com/images/kes02/post/936734c7-80dd-4883-86f1-3a0dd556964a/image.png)
3. Appscript로 HTML 폼도 제작이 가능하다. 이때 폼 디자인은 사용자가 맞춤 커스터마이징이다.
4. HTML 폼의 데이터와 시트를 매핑할 수 있다.
5. Appscript를 통해 알림톡 API 사용

## 1. 시트 기반 가시화된 DB로 사용할 수 있다.
이것은 일반 사무직들이 주로 사용하는 엑셀이 개발자들이 사용하는 DB라고 생각하면 이해하기 쉬울 것 같다.
회사에서 보통 엑셀을 사용하는 것은 물품 관리, 사용자 리스트 등의 데이터를 다루는 곳이다.
즉, 개발자가 아닌 사람들도 알게모르게 자신이 하나의 DB를 사용하고 있던 것이다.
나는 특히 개발자가 아닌 사람들도 유지보수를 할 수 있도록 하는 것이 중점이었기 때문에 서버가 아닌 시트를 DB로 사용하는 것을 채택했다.

## 2. 파일의 분리
기능별로 파일을 분리한다는 것은 생각보다 중요한 부분이다.
개발자든 개발자가 아니든 한눈에 무슨 파일이 어떤 기능을 갖고 있는지 알기도 쉽고 유지보수하는데도 중요하다고 생각한다. 그런 부분에서 파일을 분리 할 수 있는 것 또한 장점이라고 생각한다.

## 3. 맞춤 HTML 폼 커스터마이징
우리는 흔히 구글폼 또는 네이버 폼을 사용한다. 그리고 이는 되게 쉽게 사용할 수 있고 편리하다. 
그러나 회사의 로고나 디자인, 필요한 정보를 맞춤으로 폼에 보여지도록 하고 싶었다.
또한 사용자들의 연령대가 높다는 점을 감안해 폰트 사이즈를 키우고 폼 제출 시에 사용자와 관련된 정보를 미리 열람할 수 있었으면 했다.
그래서 HTML을 활용하여 고객 ID와 브랜치 ID값을 매핑하여 사용자에게 링크별로 맞춤 데이터를 제공하도록 하며 사용자 친화적으로 폼을 개발하였다.

## 4. HTML 폼의 자동화된 시트 매핑
회사에서는 사용하는 DB에 있는 고객 데이터에 새로운 폼이 제출 시 자동으로 데이터가 update되길 바랬다.
그래서 appscript를 사용하여 개발한 HTML 폼은 고객 ID 값마다 매핑하여 HTML 폼 제출 시마다 데이터가 update될 수 있도록 개발하였다. 
이는 제출된 폼을 매번 확인하는 수고를 덜고 약간의 오류나 유지보수 발생 시에만 사용자가 직접 확인하도록 하여 관리하는 시간을 줄이도록 하였다.

## 5. 알림톡 API를 사용
보통의 CRM 솔루션들은 맞춤화된 폼을 가지고는 있었으나 알림톡 기능을 사용할 수는 없었다.
약 5~10곳을 리서치를 했었는데 약 2곳은 필요하다면 기능 개발을 따로 해주겠다는 반응이었다.
그러나 0원에 가까운 비용으로 폼의 기능과 알림톡 기능을 사용하고 싶었다.
그래서 app script를 이용해 시트의 메뉴를 삽입하여 알림톡도 발송할 수 있는 기능을 개발하였다.

## HTML 폼을 불러오는 코드
```javascript
function doGet(e) {
  var template = HtmlService.createTemplateFromFile('form');
  var customerSheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('시트 이름');
  var data = customerSheet.getDataRange().getValues();
  var headers = data[1]; // 2번째 행이 헤더
  var index = headers.indexOf('ID');
  var contact = e.parameter.contact; // Get the 'contact' parameter from URL

  var rowData = {};

  // Ensure data array has at least one row of data
  if (data.length > 1) {
    for (var i = 2; i < data.length; i++) { 
      if (data[i][index] == contact) {
        for (var j = 0; j < headers.length; j++) {
          rowData[headers[j]] = data[i][j];
        }
        break;
      }
    }
  }

  template.rowData = rowData;
  return template.evaluate();
}
```

```javascript
function doPost(formData) {
  try {
    var spreadsheet = SpreadsheetApp.getActiveSpreadsheet();
    var logHistorySheet = spreadsheet.getSheetByName('폼이 제출되는 데이터가 누적되는 시트 이름');

    // Append row to 로그_이력
    var logRow = [
      formData.customerID, // 고객 번호
      formData.customerName, // 고객명
      formData.customerPhone, // 고객연락처
      new Date(), //제출 시간 (현재 날짜와 시간)
      formData.counselor ? formData.counselor : '', // 상담자 이름
      formData.communicationType ? formData.communicationType : '', // 전화상담
      formData.communicationResult ? formData.communicationResult : '', // 대면상담
      formData.additionalNotes ? formData.additionalNotes : '', // 이력
      formData.hq ? formData.hq : '', // 본사 담당자 여부
    ];
 
    updateState(formData); //고객 상태 업데이트

    logHistorySheet.appendRow(logRow);
    return "제출되었습니다!";
  } catch (error) {
    return "오류가 발생했습니다: " + error.message;
  }
}

function updateState(formData) {
  var dbCustomerSheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('제출된 데이터가 저장될 시트');

  var id = parseInt(formData.customerID);

  //id+3인 이유는 id 값이 0부터 시작하기 때문
  dbCustomerSheet.getRange(id + 3, 17).setValue(formData.communicationType); //소통구분
  dbCustomerSheet.getRange(id + 3, 18).setValue(formData.communicationResult); //소통결과
  dbCustomerSheet.getRange(id + 3, 22).setValue(formData.additionalNotes); // 이력
}
```
