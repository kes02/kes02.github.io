### 문제
https://school.programmers.co.kr/learn/courses/30/lessons/12951

### 해답
```java
class Solution {
    public String solution(String s) {
        StringBuilder result = new StringBuilder();
        boolean isFirstChar = true; // 첫 문자인지 여부를 확인하기 위한 변수

        for (char ch : s.toCharArray()) {
            if (Character.isAlphabetic(ch)) {
                // 현재 문자가 알파벳인 경우
                if (isFirstChar) {
                    // 첫 문자인 경우 대문자로 변환하여 추가
                    result.append(Character.toUpperCase(ch));
                    isFirstChar = false;
                } else {
                    // 첫 문자가 아닌 경우 소문자로 변환하여 추가
                    result.append(Character.toLowerCase(ch));
                }
            } else if (ch == 32){
                // 현재 문자가 알파벳이 아닌 경우(숫자, 공백 등)
                result.append(ch);
                isFirstChar = true; // 다음 문자는 새로운 단어의 시작이 됨
            } else {
                result.append(ch);
                isFirstChar = false;
            }
        }

        return result.toString();
    }
}
```
