### 문제
https://www.acmicpc.net/problem/1783

### 해답
```java
import java.util.*;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int N = sc.nextInt(); // 세로 크기
        int M = sc.nextInt(); // 가로 크기

        int result = 0;

        if (N == 1) {
            result = 1;
        } else if (N == 2) {
        	// M의 크기와 관련 없이 현재 위치에서 1/2 만 갈 수 있음. 
            //이동 횟수가 3이 넘어가면 4가지 이동을 써야함
            result = Math.min(4, (M + 1) / 2); 
        } else { // N >= 3
            if (M < 7) {
                result = Math.min(4, M);
            } else {
                result = M - 2;
            }
        }

        System.out.println(result);
    }
}
```

### 배운점
시뮬레이션으로 푸는건 아니었고 수학적 조건을 찾는게 관건인 문제였다.
가로 길이인 M에 따라 결과가 달라진다는걸 알아야 했다.

N=1인 경우 한 칸만 방문 가능
N=2인 경우 위/아래 이동 불가능
N>=3인 경우 이동 횟수 4 이상인 공식을 사용하였다. 이때 M<7인 경우 방문칸이 제한된다.
이렇게 작성한 이유는 체스판이 최소 3x7크기여야 모든 이동방법을 사용 할 수 있기 때문이다.
