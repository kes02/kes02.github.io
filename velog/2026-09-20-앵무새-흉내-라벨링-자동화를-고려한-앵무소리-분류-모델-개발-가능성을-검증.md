앵무새 카페에 방문해 녹음한 데이터 약 1시간 분량을 확보하였다. 이것을 가지고 앵무새 흉내 데이터 라벨링을 자동화하기 위해 모델 개발을 고려하게 되었는데 그 이유는 다음과 같다.

처음은 사람이 직접 라벨링을 하여 모델을 학습시키고, 그것을 꾸준히 하면 되겠다 라고 생각했지만 안일하게도 0.5초 클립 100개를 라벨링하는데 1시간이 걸리게 되었다. 

그래서 이런 방식으로는 현재 확보한 데이터에 대해서는 자동으로 라벨링을 할 수 있는 모델을 만들어야겠다는 결론에 다다랐다.

그렇게 된다면 먼저 라벨링에 앞서 앵무새 소리인지/아닌지를 분류할 수 있는 모델이 필요했고 이런 흐름이 가능할지 가설을 검증할 필요성이 있었다. 그래서 해당 접근부터 진행하게 되었다.

## 고려한 전체 흐름

```
녹음 전체
  ↓ 에너지 기반 VAD (0.3~1.5초 구간) - 현재 앱 구현되어 있음
소리 구간
  ↓ 앞뒤 0.15초 여유 · peak 0.9 정규화 · 5초까지 무음으로 채움
Perch 2.0 backbone   ← 가중치 고정. 학습 X
  ↓
1536차원 벡터
  ↓ 5클래스 로지스틱 회귀 (흉내·사람·울음·잡음·겹침)
흉내 확률 → 청취 순서
```

이런 흐름을 거친 데이터를 바탕으로 앵무새 소리인지/아닌지 -> 앵무새 소리라면 흉내인지 울음인지를 구분하는 모델 개발을 고려했다.

## 파일별 역할

| 스크립트 | 하는 일 |
| --- | --- |
| `13_rank_candidates` | 5클래스 로지스틱으로 흉내 확률을 계산해 청취 순서를 뽑는다 |
| `14_scan_recordings` | 녹음 전체를 훑어 흉내 후보를 새로 찾는다 |
| `15_rescore_two_stage` | 2단계(사람vs흉내) 재채점한다 |

5클래스로 하게 된 이유는 기존에 단순하게 사람과 흉내 만을 구분하였을 때 원하는데로 라벨링이 되지 않았다. 처음 기준으로 80퍼센트 정도의 정확도를 보였던 것으로 기억한다. 그래서 5클래스로 세분화 하여 흉내, 사람, 울음, 잡음, 겹침으로 데이터를 라벨링해 분류기를 만들었다.

## 사람에 비해 확실히 빨라짐

사람이 1시간에 100개를 라벨링하던 작업을, 한번 모델을 실행하면 5초 창 단위로 이만큼을 처리해주었다.

| 대상 | 5초 창 | 처리 시간 |
| --- | --- | --- |
| 실험 데이터 1.4시간 | 1008개 | 27초 |
| S3 수집분 3시간 | 2160개 | 58초 |

그렇지만 정확도는....

## 라벨 없이도...?

라벨을 다는 것은 병목이라 라벨이 없을 때도 적용 가능한지 시험했다.

| 방법 | 결과 |
| --- | --- |
| K-means 군집화(정답 안 씀) | NMI 0.003~0.032으로 실패 |
| one-class(울음만 학습, 흉내 라벨 0건) | AUC 0.950으로 성공 |
| 단어 클립과의 최대 유사도(흉내 라벨 0건) | AUC 0.988로 성공 |

K-means가 실패한 이유가 중요하다. **군집을 가른 기준은 녹음 환경이었다. 소리가 흉내냐 울음이냐는 기준이 아니었다.** 임베딩에서 변동이 가장 큰 축이 녹음 환경이기 때문이다. (이건 생각도 못했던 이슈)

one-class는 발상을 전환한 것이다. 흉내를 정의하지 말고, 울음만을 학습해서 아닌 것을 흉내로 보았고 울음 소리가 잘 수집되었다보니 확실히 정확도는 높은 결과가 나왔다.

## 결론

앵무새가 흉내를 잘 내는지를 맞추는 모델을 만들기 위해 선행과제인 데이터 라벨링을 자동화할 수 있는 앵무새 목소리 분류 모델에 대한 검증을 진행해보았다.

생각보다 데이터가 적었음에도 불구하고 앵무새 소리인지/아닌지까지는 정확도가 높아 굉장히 만족스러웠다. 그렇다면 가설에 대한 검증을 끝냈고 본격적으로 S3에 업로드된 다양한 소리를 바탕으로 데이터를 라벨링하여 분류기를 학습시키면 된다는 뜻이다.

앵무새 흉내 정확도 모델이 아닌 앵무새 목소리를 분류하는지에 대한 모델부터 만드는 것에 의아할 수 있다. 그러나 한번도 시도해보지 않았던 연구과제이자 개발 기록이기 때문에 반드시 필요하다고 생각한다.![](https://velog.velcdn.com/images/kes02/post/b0aae38e-2bfa-4896-88eb-2236d004aeca/image.png)
