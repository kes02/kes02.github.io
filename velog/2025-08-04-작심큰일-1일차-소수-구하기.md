### 문제
https://www.acmicpc.net/problem/1929

### 해답
``` java
public class Main {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int M = sc.nextInt();
        int N = sc.nextInt();

        for (int i = M; i <=N; i++) {

            if (i < 2) continue; 

            boolean isPrime = true;
            for (int j = 2; j * j <= i; j++) {
                if (i % j == 0) {
                    isPrime = false;
                    break;
                }
            }

            if (isPrime) {
                System.out.println(i);
            }
        }
    }
}
```

### 배운점
j*j를 통해 i의 루트 범위까지 반복하도록 하여 시간 복잡도가 줄어들도록 하였음.
코테 에서는 Scanner 대신 BufferedReader나 Writer 사용법에 좀 더 익숙해져야 하겠다고 생각함.
