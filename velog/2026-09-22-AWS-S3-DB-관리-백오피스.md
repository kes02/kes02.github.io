먼저 라벨링을 진행할 수 있는 곳이 총 3곳이 존재
1. **백오피스**: AWS S3에 업로드 되는 모든 raw 데이터 확인 가능
2. **clip 라벨 사이트**: S3에 업로드 된 데이터 중 팀원 3명에게 묶음으로 할당되어 있고 미리 만들어둔 분류 모델을 거쳐 클립의 앵무/비앵무로 미리 분류 되어 있으나 사람 검수 필요
3. **clip의 세부 세그먼트 라벨 사이트**: 사전에 라벨링 한 clip을 다시 듣고 파형에 맞춰서 세부 라벨링이 가능한 사이트

---
### 왜 3개?

'데이터 라벨링을 위해 굳이 이렇게 많은 사이트를 만든다고?'라고 생각할 수 있다. 그러나 기존에 백오피스에서 라벨링을 하는데 불편함이 존재해 백오피스는 전체 raw 데이터와 라벨링 데이터를 볼 수 있는 것에만 초점을 맞추게 되었다.

## 1. 백오피스
**해당 데이터는 동의한 사용자에 한해 수집되며 90일이 지나면 삭제된다.** 
***사용자 허락 없는 데이터 수집은 절대 불가하다.***

### 전체 데이터 화면
처음 접속하면 아래와 같은 페이지를 볼 수 있다. 
검색창을 통해 라벨링 된 데이터나, 캡쳐 기간, 앵무새 종으로 검색도 가능하다.
- 사용자 ID: firebase에 연동된 unique ID
- 단어: 사용자가 현재 가르치고 있는 단어가 무엇인지
- 앵무새 종: 사용자가 등록해둔 앵무새 종
- 구간: 학습구간/휴식구간 어디에서 녹음이 되었는지
- 사이클: 세션안에 세부적인 사이클(한 사이클 안에 학습/휴식 구간 -> 여러개가 합쳐짐 = 세션)
- 캡쳐 기기: AOS/iOS 사용자별 음질차를 고려하기 위한 데이터
- 라벨: 라벨링 해둔 것에 대해 표시되는 부분

'전체 내보내기'의 경우 현재는 라벨링 된 데이터에 한해서만 다운로드를 받을 수 있는 상황이다.
