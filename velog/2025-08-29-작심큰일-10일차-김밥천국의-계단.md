### 문제
https://www.acmicpc.net/problem/28069

### 해답
```java
import java.util.*;
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int N = Integer.parseInt(st.nextToken());
        int K = Integer.parseInt(st.nextToken());

        // BFS
        Queue<int[]> q = new LinkedList<>();
        q.add(new int[]{0, 0}); // {현재 계단, 사용한 횟수}

        // visited[i] = 해당 계단을 최소 몇 번만에 방문했는지
        int[] visited = new int[N + 1];
        Arrays.fill(visited, -1);
        visited[0] = 0;

        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int pos = cur[0];
            int cnt = cur[1];

            // 정확히 K번에 도착
            if (pos == N && cnt == K) {
                System.out.println("minigimbob");
                return;
            }

            if (cnt >= K) continue;

            // 1칸 오르기
            if (pos + 1 <= N && (visited[pos + 1] == -1 || visited[pos + 1] > cnt + 1)) {
                visited[pos + 1] = cnt + 1;
                q.add(new int[]{pos + 1, cnt + 1});
            }

            // 지팡이
            int nxt = pos + (pos / 2);
            if (nxt <= N && (visited[nxt] == -1 || visited[nxt] > cnt + 1)) {
                visited[nxt] = cnt + 1;
                q.add(new int[]{nxt, cnt + 1});
            }
        }

        System.out.println("water");
    }
}
```

### 배운점
dp를 처음 배울 때 계단 문제를 푸는데 그 문제에서 진화한 문제 같았다.
dp가 아닌 bfs로 풀었는데 모범답안에서 dp로 푼 부분이 훨씬 더 간단해서 조금 아쉽게 푼 문제 같다.
큐를 사용할 때 큐 내부에 배열을 집어넣는 형태를 많이 사용하는데, 이 부분도 잘 기억해두면 좋은 것 같다.
마찬가지로 bfs로 풀었기 때문에 visited 불리언형을 사용하였다.

핵심은 1칸을 오를지 순간이동할지 이 점화식을 작성하는 부분이 관건
