  • 단어 반복 재생, 보호자 목소리 녹음

  • 앱이 재생한 단어가 마이크로 다시 들어와 앵무새 발화로 잘못 기록될 가능성

  • 팀장·PM 3인 팀의 프로젝트 진행 관리
  • 마케팅 팔로워 1,000명이 넘는 채널 운영
  • 앱·서버 React Native(Expo)로 학습 세션·오디오 경로·WebRTC Viewer 개발, FastAPI 판정 서버 연결
  • 자동화 EAS·GitHub Actions·Maestro로 배포·테스트 자동화
