### 문제
https://www.acmicpc.net/problem/14495

### 해답
```java
import java.util.Scanner;

public class Solution {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt(); 

        long[] dp = new long[n + 1]; // f(n)은 최대 116이므로 long 타입 사용

        // 초기값
        dp[1] = 1;
        if (n >= 2) dp[2] = 1;
        if (n >= 3) dp[3] = 1;

        // 점화식 적용
        for (int i = 4; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 3];
        }

        System.out.println(dp[n]);
    }
}
```

### 배운점
피보나치 수열 문제를 한 번쯤 풀어봤다면 간단히 풀 수 있는 문제였다.
대신에 dp 배열에 들어가는 값이 int형의 최대 값보다 클 수 있기 때문에 long형을 사용하여야 했다.
자료형 선택에 있어 문제에서 구하고 싶은 것에 대한 자료형의 범주가 넘어가는지 문제를 풀 때 늘 고려해야한다.
