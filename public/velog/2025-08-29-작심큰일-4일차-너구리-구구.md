### 문제
https://www.acmicpc.net/problem/18126

### 해답
```java
import java.util.*;

public class Solution {

    static class Node {
        int to, cost;
        Node(int to, int cost) {
            this.to = to;
            this.cost = cost;
        }
    }

    static ArrayList<Node>[] tree;
    static boolean[] visited;
    static int maxDistance = 0;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int N = sc.nextInt(); // 방의 개수

        tree = new ArrayList[N + 1];
        visited = new boolean[N + 1];

        for (int i = 1; i <= N; i++) {
            tree[i] = new ArrayList<>();
        }

        for (int i = 0; i < N - 1; i++) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            int c = sc.nextInt();

            tree[a].add(new Node(b, c));
            tree[b].add(new Node(a, c));
        }

        dfs(1, 0); // 입구 1번 방에서 시작, 누적 거리 0

        System.out.println(maxDistance);
    }

    static void dfs(int current, int distance) {
        visited[current] = true;

        if (distance > maxDistance) {
            maxDistance = distance;
        }

        for (Node next : tree[current]) {
            if (!visited[next.to]) {
                dfs(next.to, distance + next.cost);
            }
        }
    }
}
```

### 배운점
Node 클래스를 작성하여 이를 활용하여 dfs 탐색을 하도록 하였다.
평소 사용하지 않는 클래스 생성법을 활용하였는데 오히려 이게 더 헷갈려서 실제 시험에서 적용하기 어려울 것 같았다. 
dfs 알고리즘의 문제 풀이 시 visitied를 거의 무조건 사용하는 편인 것 같아서 기억하면 좋을 것 같다.
