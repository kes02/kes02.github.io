### 문제
https://www.acmicpc.net/problem/17265

### 해답
```java
import java.util.*;

public class Solution {
    static int N;
    static char[][] board;
    static int maxVal = Integer.MIN_VALUE;
    static int minVal = Integer.MAX_VALUE;
    static int[] dx = {1, 0}; // 아래, 오른쪽
    static int[] dy = {0, 1};

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        N = sc.nextInt();
        board = new char[N][N];

        for (int i = 0; i < N; i++)
            for (int j = 0; j < N; j++)
                board[i][j] = sc.next().charAt(0);

        dfs(0, 0, board[0][0] - '0', ' ');

        System.out.println(maxVal + " " + minVal);
    }

    static void dfs(int x, int y, int curValue, char oper) {
        if (x == N - 1 && y == N - 1) {
            maxVal = Math.max(maxVal, curValue);
            minVal = Math.min(minVal, curValue);
            return;
        }

        for (int dir = 0; dir < 2; dir++) {
            int nx = x + dx[dir];
            int ny = y + dy[dir];
            if (nx >= N || ny >= N) continue;

            char next = board[nx][ny];
            if (next == '+' || next == '-' || next == '*') {
                dfs(nx, ny, curValue, next);
            } else { // 숫자
                int num = next - '0';
                int newValue = calc(curValue, oper, num);
                dfs(nx, ny, newValue, ' ');
            }
        }
    }

    static int calc(int a, char oper, int b) {
        switch (oper) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            default:  return b; // 첫 숫자일 땐 oper이 공백이므로 숫자 그대로
        }
    }
}
```

### 배운점
문제에서 연산자는 +, -, * 만 나온다고 했기 때문에 해당 부분에 대해서는 함수로 작성
dfs를 사용하여 모든 경로를 확인하여 계산 결과를 알아야했다.
이때 map의 맨 아래에 메모이제이션을 통해 반복 방지를 해야 했다.
그리고 연산자의 우선순위를 생각해서 푸는 문제는 아니다.
