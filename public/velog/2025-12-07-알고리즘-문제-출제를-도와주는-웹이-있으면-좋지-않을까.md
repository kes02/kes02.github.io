## 요약
현재는 많은 유저들을 유치해서 사용하고자 하는 서비스가 아닌 단순하게 **자신이 코테 스터디를 하거나 코테 준비**를 함에 있어 일일이 문제를 찾고, 고민하는 시간을 줄이고자 개발한 웹서비스입니다.
- 사용해보시고 <u>간단한 코멘트나 추가/수정했으면 하는 부분은 언제든 환영입니다!</u>
- 소스는 오픈되어 있습니다. 

### 만들게 된 계기
취준을 위해 여러 사람들과 코테 스터디를 하다보니 알고리즘 문제를 출제하는 것이 **어렵고, 생각보다 오랜 고민**을 해야한단 것을 깨달았습니다.
백준에 만들어진 다양한 문제 출제집의 경우 팀원들이 어떤 문제를 풀었고, 풀지 않았음을 일일이 확인하는 것이 번거로웠습니다.
<u>그래서 백준 아이디만으로 팀원들이 풀지 않은 문제들 중, 조건에 따라 랜덤하게 백준 문제를 출제할 수 있으면 스터디를 함에 더 편리할 것이라고 생각했습니다.</u>

또한 실제로 우리가 코테를 보게 될 때도 몇 문제가 출제될지만 알고, **어떤 알고리즘과 어떤 난이도로 출제될지는 랜덤**하기 때문에 해당 부분에서도 도움이 될 것이라고 생각합니다.

### 그래서 만들게 된 웹사이트
1. 코테 스터디의 알고리즘 문제를 선별하기 위해 아이디를 등록하는 부분
- 문제 출제를 위해 스터디원의 백준 아이디를 모두 등록 
- 1개 이상 등록 (사용자의 웹 local Storage에 저장)
![](https://velog.velcdn.com/images/kes02/post/453d1ae3-17da-4010-9011-5fbcff1f146b/image.png)

2. 문제 출제 조건 설정을 하는 부분
- 등록된 아이디에서 풀지 못한 문제만을 조건에 맞게 하단에 생성
- 난이도(브론즈 ~ 루비), 기준(랜덤, 제출 많은 순, 정답 비율이 높은 순), 언어(한국어, 중국어, 일본어), 알고리즘(dfs/bfs, two pointer, greedy 등), 검색(모든 알고리즘 포함, 하나라도 포함), 문제수
![](https://velog.velcdn.com/images/kes02/post/6e853726-61a8-4d5e-9540-af41a28fb844/image.png)

### 추가하거나 수정하면 좋을만한 부분
1. 알고리즘 태그는 현재 **영어**로만 검색이 가능하기 때문에 사용자가 어떤 알고리즘이 제공되는지 알기 어려운 상황이라, 어떤 알고리즘이 제공되는지 명시하는 기능 제공
2. 팀장과 팀원 role을 구분하여 관리할 수 있는 형태 -> 로그인이나 코드 형태로 DB 백업 필요
3. 이메일 alert 기능을 통해 설정해둔 시간마다 스터디 alert -> DB 필요

### 후기
요즘 프론트엔드 개발을 하다보니 solved.ac에서 제공하는 api를 활용하면 제가 고민하고 있던 부분에 돌파구가 생긴 것 같아 진행해본 토이 프로젝트입니다.

프로그래머스나 잡다에서 사용하는 타 알고리즘 문제 플랫폼에서도 문제를 가져올 수 있게된다면 문제를 가져올 수 있도록 확장할 계획도 있습니다.
