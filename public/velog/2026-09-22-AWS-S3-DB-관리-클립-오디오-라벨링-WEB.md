### 배경
앞에서 세그먼트만을 라벨링 하였을 때 한 오디오에 여러가지 소리가 섞여있었다. 이를테면 사람 소리, 차소리, 앵무새의 짹짹소리 등이 포함되어 있었다. 그렇다면 이 소리는 여러가지의 분리된 또는 겹쳐진 파형으로 세그먼트 오디오 안에 보여진다.

기존에는 세그먼트 내에 존재하는 모든 소리에 대해 라벨링을 진행했다면, 클립 오디오 라벨링은 세그먼트 내의 세부적인 오디오 파형을 라벨링 하려고 하였다.
마찬가지로 데이터 병합은 PR 형태로 진행하였다.

## 3. 클립 오디오 라벨링 WEB
### 라벨링 화면
세그먼트 오디오 라벨링 화면과 동일하게 파형을 볼 수 있고, 듣기도 할 수 있다. 
한가지 다른 점은 세그먼트에서 라벨링 된 태그가 뭔지 미리 볼 수 있고, 확대를 통해 더욱 세부적으로 파형 별로 라벨링을 할 수 있다.
![](https://velog.velcdn.com/images/kes02/post/53572ff1-a83e-4cac-8114-f27c812a51fc/image.png)

### 클립 세분화 기능
왼쪽 목록에서 reviewed라고 표시된 것은 클립 라벨링을 진행한 것이고, unstarted를 선택해 클립 라벨링을 진행할 수 있다.
특히, 0.3초 ~ 0.4초 사이에 있는 흰 줄을드래그 해 파형이 있는 곳으로 옮긴 뒤 키보드 'A'를 누르면 파형이 있는 부분을 자동으로 인식해 구간을 잡아줘서 굉장히 편리하다.
![](https://velog.velcdn.com/images/kes02/post/e9244075-b500-4eb3-b399-8d6a751c798b/image.png)
